# BranchOut

Code and supplementary materials for the AINL 2026 paper **"Branching Out, Not Breaking Down: An Agentic Pipeline for Visual Novel Script Generation"**.

BranchOut is a staged multi-agent pipeline for generating visual novel scripts as structured JSON artifacts. It separates planning, asset construction, scene contracts, writing, critique, and assembly, and includes retrieval-based context, explicit branch-local story state, divergence snapshots, schema validation, and location-affordance checks.
